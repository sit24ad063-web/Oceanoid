# Oceanoid — AquaMind

AquaMind is a professional real-time ocean intelligence web application demo featuring:

- Mission-control dashboard layout
- Live GIS map (Leaflet) with bot tracking and operational layers
- Coral monitoring, infrastructure alerts, and sensor cards
- AI vision simulation panel and mission assistant chat
- Mode switching (Monitoring, Alert, Exploration, Prediction, Engineer, Ecology)
- Instant multilingual UI switching (English/Tamil)

## Run locally

Because this project is static HTML/CSS/JS, run any local web server from the project root:

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`
